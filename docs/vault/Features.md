# Features

- [[Live Screen]] — stream the Mac's display; Pointer / Touch / View modes
- [[Hand Mouse]] — camera gesture control with a pose latch
- [[Gesture Studio]] — record custom poses, map to actions
- [[TV Mode]] — Mac on a TV, phone as remote
- [[Desktops and Windows]] — Spaces, previews, jump-to-app
- [[Media and Audio]] — playback, volume, video scrubbing, speaker picker
- [[Wake and Remote Access]] — Wake-on-LAN, connect by address
- [[Monetization]] — Pro unlock and trial
