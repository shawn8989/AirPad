# How This Vault Is Organised

```
00 Index.md            ← start here (map of content)
Overview.md            ← the pitch
Architecture.md        ← how the pieces fit
Features.md            ← index of feature notes
Decisions.md           ← why things are the way they are
Apps/                  ← one note per app
Features/              ← one note per feature
Release/               ← shipping: checklist, naming
Roadmap/               ← what's next, with designs
Meta/                  ← this folder
```

**Conventions.** `[[Wiki links]]` between notes, YAML `tags:` at the top, and
one idea per note. Notes describe *decisions and behaviour*, not code — code
changes faster than prose, and a note that restates code goes stale immediately.
