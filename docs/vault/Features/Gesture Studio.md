# Gesture Studio

Record your own hand pose, map it to an action. Templates are matched by cosine
similarity against a feature vector; a match suppresses built-in gestures so the
two systems can't fight.

**Actions available.** Key chord, media key, desktop left/right, Mission
Control, type text, launch app (by bundle ID), open URL. 32 curated presets.

The three built-in hold gestures (palm-hold, thumbs-up, shaka) are **remappable**
through the same action picker — stored in UserDefaults `builtinGestures.v1`.
