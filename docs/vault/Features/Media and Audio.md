# Media and Audio

- Now Playing (Music/Spotify via AppleScript) + volume slider
- Volume / playback / brightness media keys
- **Scrub Video** — Rewind/Forward send the arrow keys players honour,
  repeated 1/2/4× for Small/Medium/Large. macOS has **no** system-wide "skip
  10 seconds"; media keys only change track, so distance varies by player.
- **Mac Sound Output** — remote CoreAudio device switcher (TV, headphones,
  built-in). Only devices the Mac already knows about appear.
- Clipboard both directions
