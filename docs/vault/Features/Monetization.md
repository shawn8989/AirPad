# Monetization

- **Free:** trackpad, keyboard, media, clipboard.
- **Pro:** Live Screen, Hand Mouse, Gesture Studio, Desktops. One-time
  non-consumable `com.airpad.pro.lifetime`. **Product ID is hardcoded and
  cannot be changed after creation.**
- **Trial:** 7 days of everything, stored in Keychain — survives reinstall, so
  it is one trial per *device*, not per install (deliberate).
- **No accounts.** StoreKit entitlements + Restore Purchases are the ledger.
- **No ads.** Rejected: economics don't work at this scale and it contradicts
  the privacy pitch. See [[Decisions]].
